# Google ADK Agent Catalog

60 practical AI agents built with Google ADK. Each agent is independently importable and can later be composed into an orchestrator.

See `AGENTS.md` for the catalog and `agents/catalog.py` for the implementation.

## Setup

```bash
pip install google-adk google-genai
gcloud auth application-default login
export GOOGLE_CLOUD_PROJECT=YOUR_PROJECT_ID
export GOOGLE_CLOUD_LOCATION=us-central1
```
